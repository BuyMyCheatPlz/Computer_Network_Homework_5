# 作业 5 提交与现场验收

交付程序为 Python 客户端与 C++17 服务端。双击 `start.bat` 打开图形界面，先在“服务器管理”启动服务，再注册、登录。已提供服务端 EXE，无需先编译。

## 已完成

- 注册、登录、注销、账号持久化和在线成员自动更新。
- UTF-8 中文与英文群聊，真实 UDP 组播，TTL=1。
- 选中多位成员后，经 TCP 定向发送；未选中成员不接收。
- 报文 SHA-256 完整性校验、无效任务码与错误参数处理。
- 组播确认、约 800ms 后 TCP 补发和客户端去重。
- 真实 C++/Python 集成测试 12 项通过，原始结果随包附带。
- 根据指定模板制作 Word 与 PDF 报告，含协议详细设计和核心源码附录。
- 封面信息、封面题目示例文字和教师评语页遵照用户要求保留原样。
- 720p MP4 演示，中文系统语音讲解，时长小于 3 分钟。
- 标准 RAR5 提交包，小于 100MB；文件与报文使用不同的 CRC/SHA 校验机制。

## 仍需本人现场完成

1. 两台或多台实体电脑接入同一局域网，客户端填写服务器真实局域网 IPv4；多网卡时指定本机组播网卡。
2. 在聊天记录中确认实际出现“UDP 组播”，不能将“TCP”补发记录当作跨机组播成功。
3. 验证双向中文群聊、选中两人的定向隔离、注销后的名单同步。
4. 核对老师课程的提交命名规则及封面信息；本次按要求没有替换模板上的任何封面字段。
5. 在截止时间 **2026-11-20 23:59** 前，将 RAR 上传至课程指定系统。

现有网络实测与录像均来自本机真实 TCP/UDP 进程；没有虚构跨机测试、校园网性能或个人课程心得。程序没有离线消息、历史记录持久化、TLS 或消息认证码，报告已说明范围。
